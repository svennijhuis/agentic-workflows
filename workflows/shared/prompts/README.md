# Action-only prompt snippets

Use this folder for Markdown the **Actions** agent should inject (`{{#runtime-import}}` or extra shared files).

Do **not** paste SKILL.md from [agentPacks](https://github.com/svennijhuis/agentPacks). Those load through `plugins:` / `skills:` so IDE and CI stay on one source.

Good candidates: “how to write the weekly org status comment”, label taxonomy, `import-schema` templates for parameterized reviews.
