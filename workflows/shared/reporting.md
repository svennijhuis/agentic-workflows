---
description: Fixed report format for issues, PR comments and reviews. Optional title prefix via import-schema.
import-schema:
  title-prefix:
    type: string
    description: Prefix for issue and review titles.
    default: "[aw]"
---

## Report format

Every issue, comment or review this workflow writes uses this shape, in plain ASCII (no en or em dashes):

1. Title: `${{ github.aw.import-inputs.title-prefix }} <short summary>`
2. `### Summary`: one or two sentences.
3. `### Findings`: one bullet per finding as `path:line: finding`.
4. `### Next step`: one line, or `none`.
5. Footer: `Generated by <workflow> (report only).`
