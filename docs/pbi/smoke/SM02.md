## Goal
While a feature is built, the agent turns the PBI acceptance criteria into new smoke scenarios that ship in the same PR.
## Context
The workflow is authored here as `workflows/smoke-writer.md` (agentic sources live in `workflows/`, see `docs/reference/layout.md`) and installed into the API repo `svennijhuis/<api repo>` with `gh aw add` at a tag, where the feature PRs and the `smoke/<feature>/` folders live (SM01). It is `workflow_dispatch` only (POL25, PA1) and `safe-outputs.staged: true` until Sven promotes it in `governance/rollout.yml` (POL03). It spends tokens, so the door is one-way.
## Steps
1. Write `workflows/smoke-writer.md`: `workflow_dispatch` only (inputs: PBI id, PR number), shared defaults import, caps, `safe-outputs.staged: true`.
2. Prompt: behavior not procedure; the workflow reads the PBI file and the PR diff with tools, writes only under `smoke/<feature>/`.
3. Staged dry run on one past feature PBI on the X01 trial repo.
## Definition of Done
- [ ] `workflows/smoke-writer.md` has `on: workflow_dispatch` only; no other trigger (POL25)
- [ ] `safe-outputs.staged: true` until Sven's yes promotes it in `governance/rollout.yml` (POL03)
- [ ] Reads the PBI file and the diff; writes only under `smoke/<feature>/`
- [ ] One scenario per acceptance criterion that touches an endpoint; skips with a reason line otherwise
- [ ] Output passes `scripts/check-smoke.sh`; Tester and Reviewer review it like code
- [ ] Safe outputs: one commit or one PR comment, nothing else, each with a `max`
- [ ] Every Bar H line from [README.md](../README.md#bar-h-every-workflow-pbi): shared defaults import; pinned gh-aw plus import SHA or tag; caps (`max-ai-credits`, `max-daily-ai-credits`, `max-turns`, `timeout-minutes`); pre-check then noop; staged or report-only first; dedupe; `min-integrity: approved`; minimal network allowlist; tool allowlist; threat detection on; `on.roles` plus skip-bots; fixed PR format; trial-repo run on X01; audit of first 3 runs; measured cost per run in Evidence; the workflow fetches its own context; X07 benchmark at or above baseline
## Technical design
- Components and files: catalog: `workflows/smoke-writer.md`, `workflows/smoke-writer.lock.yml`, `workflows/smoke-writer.card.yml` (POL24); API repo `svennijhuis/<api repo>`: installed copy, `smoke/<feature>/scenarios.yml`
- Module boundary: input PBI id and PR number, output one commit under `smoke/<feature>/` or one comment; the acceptance criteria to scenarios prompt sits behind it
- Interfaces: `workflow_dispatch` inputs PBI id, PR number; safe-outputs one commit under `smoke/<feature>/` or one comment (staged first); exit 0/1/2 (PA5)
- Sequence:

```mermaid
sequenceDiagram
  participant B as Builder PR (API repo)
  participant W as smoke-writer (dispatch, staged)
  participant C as check-smoke.sh
  B->>W: PBI id + PR number
  W->>W: read PBI and diff, AC to scenarios
  W->>C: scenarios.yml
  C-->>W: 0 or 1
  W->>B: staged commit or comment under smoke/feature/
```

- Failure modes: no endpoint in AC: comment with skip reason; check fails: exit 1, max 1 retry, then 2 needs-human
- Security: no network to tst/acc from the writer, no secrets, write path limited to `smoke/`, read-only tools otherwise
- Observability: run id + scenario count in PR comment
- Cost: AIC per run; staged dry runs only until Sven's yes
- Rollback: delete the workflow and its lock, revert
- Proof: same as proof: above
- Door: one-way (token spend; Sven's yes before the first real run)
